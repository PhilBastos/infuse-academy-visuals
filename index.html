03
The script
TOOL
Claude (Anthropic) → HTML + SVG
The story is about a gap too small to notice. Each panel shows the team drifting away from the platform while one line underneath shows why: a few degrees off on day one becomes a missed opportunity by month six. The panels darken as the story does.
WHY AI
I used Claude as a generative design partner: I set the concept, composition, palette and type, and it wrote the code that renders each visual — a procedural knot, a particle funnel, an animated storyboard. Code-generated art stays crisp at any size, animates for free and follows the brand system exactly, which image generators still struggle with.
